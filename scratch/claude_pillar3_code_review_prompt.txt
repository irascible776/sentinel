### 1. Key Architectural Implementations:
1. Anti-TOCTOU Pixel Canonicalization (`core/vision/preprocessing/image_prep.py`):
   - Safely decodes untrusted input images with decompression bomb caps (`MAX_IMAGE_PIXELS = 50_000_000`).
   - Normalizes orientation via EXIF.
   - Flattens transparent/alpha channels onto opaque neutral background (prevents transparent overlay / CSS blend exploits).
   - Strips all metadata, EXIF, IPTC, polyglot trailers.
   - Re-encodes to pristine canonical PNG before downstream inspection.
2. Fast-Path Text-Presence Gate (`core/vision/preprocessing/text_presence.py`):
   - Sub-millisecond horizontal and vertical spatial gradient variance across 16x16 blocks.
   - Clean photographs (<0.04 block ratio) bypass heavy OCR within <15ms.
3. Resilient Multi-Backend OCR (`core/vision/ocr/`):
   - Dynamic capability probing: EasyOCR (M1 MPS/GPU) -> Tesseract (CPU fallback) -> Deterministic Mock (CI).
   - Zero-crash guarantee if optional OCR libraries are absent.
4. Semantic Zero-Text Concept Bank (`core/vision/semantic/`):
   - MobileCLIP-S0 (512-d embeddings, ~45MB footprint, unified memory friendly).
   - Precomputed L2-normalized centroids for CSAM, weapons, violent contraband, graphic violence.
   - Benign enterprise anchor margin scoring: `margin = d_benign_min - d_threat_min`. Requires `margin > 0.08` to trigger, preventing false positives on tools, hardware, and charts.
5. SRM High-Frequency Residual & Stego Analysis (`core/vision/srm/`):
   - 10 Spatial Rich Model high-pass convolution kernels.
   - Edge-residual correlation and flat-region energy leakage to detect adversarial PGD/FGSM perturbations.
   - Westfeld & Pfitzmann Chi-Square test on 128 Pairs of Values (PoVs) for LSB spatial steganography.
   - Demoted to soft corrobative signals to prevent false positives on raw JPEG compression artifacts.
6. Document Threat Parsers (`core/vision/document/`):
   - PyMuPDF (`fitz`) and `python-docx` deep forensics.
   - Delta E CIE76 / Delta E 2000 perceptual color distance (<4.5 threshold) against background.
   - Effective font size computation incorporating CTM scaling matrix and bbox bounds (<3.0pt triggers MICRO_FONT).
   - OOXML `<w:vanish>` hidden run inspection and off-canvas coordinate detection.
   - Page-level max-plus-mean risk rollup (`0.65 * max + 0.35 * mean`).
7. Solid Charcoal Redaction Engine (`core/vision/redaction/`):
   - Pixel-rebuilt opaque charcoal masking (`(24, 24, 27)`) over malicious bounding boxes with audit watermark stamp.
8. Corroboration-Gated Consensus Judge (`core/vision/consensus/`):
   - Strict corroboration gates for BLOCK actions: isolated soft signals (SRM noise, low-confidence text) produce FLAG; BLOCK requires verified OCR injection, critical semantic match, or verified document stealth exploit.
   - Fail-secure: unscannable or corrupt streams trigger safe BLOCK.
