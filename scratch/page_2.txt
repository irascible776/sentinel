MalConv: 1D-CNN on Raw Byte Sequences Sentinel ingests raw, unparsed Portable Executables PE, ELF binaries, and Mach-O files directly as byte arrays without requiring manual feature engineering, disassembly, or unpacking. ● Architecture: The input stream is parsed as a sequence of integer byte values $x \in 0, 1, \dots, 255^L$ (padded or truncated to $L = 2 \times 10^6$ bytes). An nn.Embedding layer maps each byte value to an $8$-dimensional continuous vector space. The architecture applies parallel 1D Convolutional layers ( nn.Conv1d ) with wide kernel sizes $k=500$, stride $s=500$ to capture localized structural constructs (such as PE headers, import address tables, and shellcode sequences). To allow broad receptive fields, the network employs a Gated Convolutional mechanism (element-wise multiplication of activated features and linear gates), followed by Global Max Pooling ( nn.AdaptiveMaxPool1d ) to extract scale-invariant features regardless of offset within the binary. ● Loss Function: Binary Cross-Entropy with Logits ( nn.BCEWithLogitsLoss ) trained to output a probability score representing malicious versus benign intent. 2. MalImg: 2D-CNN Byte-to-Image Representation To leverage standard Computer Vision backbones for malware family classification, binaries are rendered into 8-bit grayscale images. ● Pipeline: A raw binary string is mapped into a 1D array of 8-bit unsigned integers $0 \dots 255$ and shaped into a 2D matrix of fixed width $W$ (determined by binary size: e.g., $W128$ for $10$ KB, $W1024$ for $1000$ KB. The height $H$ varies dynamically based on total file size. The resulting 2D matrix is resized via bilinear interpolation to $224 \times 224 \times 1$. ● Architecture: ResNet-18 / EfficientNet backbone pretrained on ImageNet (adapted for single-channel input). Transfer learning fine-tuning allows the extraction of spatial macro-structures (e.g., resource sections appear as dense uniform textures, whereas encrypted code sections exhibit high entropy/noise patterns). ● Classification: Multi-class Cross-Entropy Loss over known family categories (e.g., Ramnit, FakeRean, Yuner, KAZO ). 3.
