LLM Tool-Call Argument Inspection Engine When an agent generates a JSON schema tool call (e.g., execute_sql(query=...) or run_terminal_command(cmd=...)), Sentinel intercepts the payload before execution. ● Validation Pipeline: a. JSON Schema Validation: Validates argument types against strictly defined structural schemas. b. Deterministic Regex Filtering: Blocks known command injection syntax (e.g., ; rm -rf , && , | , $(...) , UNION SELECT ). c. Semantic Threat Classification: Passes the parameter values through a light DistilBERT model trained on shell command and SQL injection corpora to catch obfuscated payload attempts (e.g., base64 encoded command execution). 2.
